# MommyCare (맘편한 하루) 🤰

**MommyCare** is a native Android application designed to provide comprehensive healthcare support for expecting mothers. It integrates health tracking, community engagement, and location-based medical services into a single, user-friendly platform. 

[20230818_이서진.pdf](https://github.com/user-attachments/files/24354336/20230818_.pdf)




## 🚀 Key Features

* **Health Record Management**: A structured diary for mothers to record daily physical conditions and emotional well-being. 
* **Hospital & Care Center Locator**: Integrated **Kakao Maps API** to provide real-time, location-based searches for nearby hospitals and postpartum care centers. 
* **Community Platform**: A dedicated space for users to share experiences, ask questions, and build a supportive network. 
* **User-Centric UI/UX**: Designed with a focus on accessibility and ease of use, tailored specifically for the needs of pregnant users. 

## 🛠 Tech Stack

* **Language**: Kotlin 
* **IDE**: Android Studio 
* **APIs**: Kakao Maps API (Location-based services)
* **Design**: User-centered UI/UX design for healthcare accessibility
